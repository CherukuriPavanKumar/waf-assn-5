# Assignment 5

Each question is independent and is kept in its own folder.

## Node and Express questions

Install the one dependency from this folder:

```bash
npm install
```

Run a server with one of the scripts in `package.json`, for example:

```bash
npm run q3
```

Questions 1 and 2 use only built-in NodeJS modules:

```bash
node question1/server.js
node question2/app.js
```

The Express servers use ports 5000 through 5007, then 5011, 5014, and 5015. The port is printed when each server starts.

## React questions

Open `question11/index.html` through `question13/index.html`, `question15/index.html`, or `question16/index.html` in a browser. These examples load React and Babel from a CDN and require internet access.
